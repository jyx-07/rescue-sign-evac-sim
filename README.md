# 구조판 — AI 기반 스마트 화재 감지 및 실시간 대피 유도 시스템

가스·연기 센서로 화재를 감지하고, AI가 경로 위험도를 판단해 비상구 표지판 화살표를 실시간으로 바꾸며, 초음파 센서와 외벽 LED로 구조대에게 사람이 남아 있을 수 있는 위치를 알려 주는 시스템입니다. 이 저장소에는 시연용 3D 시뮬레이션, 실물 모형용 아두이노 코드, AI 서버가 함께 들어 있습니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `simulation/` | 3D 비교 시뮬레이션 (`evac-compare.html`) |
| `arduino/` | 아두이노 우노 스케치: 서보 4개, 초음파 센서 2개, 외벽 LED 2개, 가스 센서 |
| `ai/` | 대피 방향 판단 AI 서버 (입출력 형식과 예시 서버). 자세한 내용은 [ai/README.md](ai/README.md) |
| `발표용 실행 (Mac).command`, `발표용 실행 (Windows).bat` | 더블클릭하면 시뮬레이션을 띄우고 크롬(없으면 엣지)으로 엽니다 |

## 시뮬레이션 내용

같은 2층 아파트 두 동에서 같은 위치에 불이 납니다.

- **A 동 (일반 비상구 표지판):** 방향이 고정되어 가장 가까운 계단만 가리킵니다.
- **B 동 (구조판):** 센서 위험도를 초록(정상)·주황(주의)·빨강(위험)으로 표시하고, AI가 복도 구간마다 어느 계단이 더 안전한지 확률로 판단해 화살표를 돌립니다. 연기가 찬 계단 입구 표지판은 빨간색으로 바뀝니다.

**발화 위치(상황)**는 화면 하단 버튼으로 고릅니다: 2층 왼쪽, 2층 오른쪽, 1층 왼쪽, 1층 오른쪽.

주민 20명(성인, 어린이, 노인, 이동약자)은 유형마다 속도가 다르고, 연기 속에서는 느려지며 노출량이 쌓입니다. 계단으로 내려오지 못한 2층 이동약자 2명(202호, 204호)은 경보 12초 뒤 도착하는 사다리차가 구조합니다.

- **A 동:** 사다리차가 사람 위치를 몰라 끝 집(205호)부터 창문을 하나씩 확인합니다.
- **B 동:** 집 안 초음파 센서가 남은 사람을 감지하면 외벽 파란 LED가 깜빡이고, 사다리차가 그 집으로 바로 갑니다.

화면 하단에서 대피 완료 인원, 경과 시간, 평균 연기 노출량, 사다리차 구조 진행을 실시간으로 비교합니다.

## 실행

`발표용 실행 (Mac).command`(윈도우는 `발표용 실행 (Windows).bat`)를 더블클릭합니다. `http://localhost:8765/simulation/evac-compare.html`이 열립니다.

- 파이썬이 필요합니다 (윈도우는 python.org에서 설치, "Add python.exe to PATH" 체크).
- three.js와 웹폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- `simulation/evac-compare.html`을 직접 더블클릭해도 시뮬레이션은 보입니다. 다만 아두이노 자동 연결과 AI 서버 연결은 실행 파일로 열어야 됩니다.

조작: 재생/일시정지, 다시보기, 속도(1×/3×/6×), 발화 위치, 드래그 회전, 휠 확대, 시점 초기화, 1F/2F 층 강조.

## AI

B 동 화살표 방향은 AI가 정합니다. 화면 B 동 패널의 "AI · ..." 줄에 어떤 AI를 쓰는지 나옵니다.

- `ai/server.py`가 있으면 실행 파일이 함께 띄우고, 페이지가 그 서버(`http://localhost:8000`)에 판단을 물어봅니다.
- 서버가 없거나 응답이 없으면 페이지 안의 내장 신경망으로 자동 전환합니다. 페이지를 열 때 시뮬레이터로 만든 상황 4,000개로 학습하며, 검증 정확도는 약 99.6%입니다.

팀 AI를 붙이려면 `ai/server_example.py`를 `ai/server.py`로 복사한 뒤 `predict_right()` 안을 우리 모델로 바꾸면 됩니다. 입출력 형식은 [ai/README.md](ai/README.md)에 있습니다.

## 아두이노 연결

연결 기능:
- 화면 B 동 표지판 방향 → 서보 4개가 실물 화살표를 돌립니다.
- 가스 센서 값이 기준을 넘으면 → 화면에서 선택한 위치에 불이 납니다. 아두이노가 연결돼 있으면 페이지는 자동으로 불을 내지 않고 가스 센서 신호를 기다립니다. 센서가 안 될 때를 대비해 "지금 발화" 버튼도 나옵니다.
- 실물 초음파 센서(202호, 204호)에 손을 30cm 안으로 대면 → 화면에서 그 집에 사람이 있는 것으로 보고 외벽 LED를 켜고, 사다리차를 그 집으로 보냅니다.
- 화면의 202호, 204호 외벽 LED → 실물 LED 2개가 같이 켜지고 꺼집니다.

순서:
1. 아두이노 IDE로 `arduino/gujopan_servo/gujopan_servo.ino`를 우노에 업로드합니다.
2. 배선합니다.
   - 서보 신호선: 3, 5, 6, 9번 핀 (서보 0: 1층 왼쪽, 1: 1층 오른쪽, 2: 2층 왼쪽, 3: 2층 오른쪽 표지판)
   - 초음파 센서(HC-SR04) 202호: TRIG 7, ECHO 8 / 204호: TRIG 10, ECHO 11 (VCC 5V, GND)
   - 외벽 LED 202호: A0 / 204호: A1 (각각 220Ω 저항을 거쳐 GND)
   - 가스 센서(MQ-2 등) 아날로그 출력: A2 (VCC 5V, GND)
3. 서보 전원은 외부 5V에 연결하고, 외부 전원 GND와 아두이노 GND를 이어 줍니다. 서보 4개를 USB 전원으로 돌리면 보드가 재부팅될 수 있습니다.
4. 실행 파일을 더블클릭합니다.
5. **처음 한 번만** 하단의 "아두이노 연결" 버튼을 눌러 포트를 고릅니다. 브라우저 보안 때문에 이 한 번은 건너뛸 수 없습니다.
6. 그다음부터는 같은 컴퓨터, 같은 브라우저에서 실행 파일로 열면 페이지가 켜지자마자 자동으로 연결됩니다. USB를 다시 꽂아도 자동으로 다시 연결됩니다.

조정할 수 있는 값 (스케치 위쪽):
- 화살표 각도 `ANGLE_LEFT`(20°), `ANGLE_RIGHT`(160°), 회전 속도 `STEP_MS`
- 초음파 감지 거리 `PRESENT_CM`(30), `ABSENT_CM`(40)
- 가스 기준값 `GAS_THRESHOLD`(400), 예열 시간 `GAS_WARMUP_MS`(20초). MQ 센서는 켠 직후 값이 높게 나오므로 예열 시간 동안은 화재로 판단하지 않습니다.

팀에서 만든 가스 센서 코드를 따로 쓴다면, 화재로 판단할 때 `Serial.println("FIRE");` 한 줄만 보내면 됩니다.

시리얼 형식 (115200bps, 한 줄에 명령 하나):
- 페이지 → 아두이노: `S,<서보번호>,<L|R>` (예: `S,2,R`), `L,<LED번호>,<0|1>` (예: `L,0,1`은 202호 LED 켜기)
- 아두이노 → 페이지: `U,<센서번호>,<0|1>` (예: `U,1,1`은 204호에 사람 감지), `G,<가스값>` (화면 표시용), `FIRE` (화재 발생)

## 참고

- 연기 확산, 이동 속도, 노출량 계산은 시연용으로 단순화한 모델이며 실측 데이터가 아닙니다.
- 내장 신경망은 시뮬레이터가 만든 데이터로 학습했고, 실제 화재 데이터로 학습한 모델이 아닙니다.
- 초음파 센서는 사람을 직접 식별하지 못합니다. "사람이 있을 가능성"으로 보고, 실제 구조 필요 여부는 구조대가 확인합니다.
