# 구조판 대피 비교 시뮬레이션

같은 화재 시나리오를 두 건물에서 동시에 재생하는 3D 시뮬레이션입니다.

- **A 건물**: 일반 비상구 표지판. 방향이 고정되어 가장 가까운 계단만 가리킵니다.
- **B 건물**: 구조판 적용. 센서가 연기를 감지하면 표지판 화살표가 회전해 연기가 없는 계단으로 안내합니다.

2층짜리 건물의 2층 왼쪽 세대에서 불이 나고, 연기가 2층 복도를 채운 뒤 왼쪽 계단을 따라 1층까지 내려옵니다. 주민(성인, 어린이, 노인, 이동약자)은 유형마다 속도가 다르고, 연기 구역을 지나면 느려지며 노출량이 쌓입니다. 화면 하단에서 대피 완료 인원, 경과 시간, 평균 연기 노출량을 실시간으로 비교합니다.

## 실행

`evac-compare.html`을 브라우저로 열면 바로 재생됩니다. 별도 설치나 서버는 필요 없고, three.js와 웹폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- 재생/일시정지, 다시보기, 재생 속도(1×/3×/6×)
- 드래그로 회전, 휠로 확대, "시점 초기화"로 기본 시점 복귀
- 층을 클릭하거나 1F/2F 버튼으로 해당 층만 강조

## 참고

연기 확산, 이동 속도, 노출량 계산은 시연용으로 단순화한 모델이며 실측 데이터가 아닙니다.
