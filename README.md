# 구조판 대피 비교 시뮬레이션

같은 화재 시나리오를 두 건물에서 동시에 재생하는 3D 시뮬레이션입니다.

- **A 건물**: 일반 비상구 표지판. 방향이 고정되어 가장 가까운 계단만 가리킵니다.
- **B 건물**: 구조판 적용. 센서가 연기를 감지하면 표지판 화살표가 회전해 연기가 없는 계단으로 안내합니다.

2층짜리 건물의 2층 왼쪽 세대에서 불이 나고, 연기가 2층 복도를 채운 뒤 왼쪽 계단을 따라 1층까지 내려옵니다. 주민(성인, 어린이, 노인, 이동약자)은 유형마다 속도가 다르고, 연기 구역을 지나면 느려지며 노출량이 쌓입니다. 화면 하단에서 대피 완료 인원, 경과 시간, 평균 연기 노출량을 실시간으로 비교합니다.

## 실행

`evac-compare.html`을 브라우저로 열면 바로 재생됩니다. 별도 설치나 서버는 필요 없고, three.js와 웹폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- 재생/일시정지, 다시보기, 재생 속도(1×/3×/6×)
- 드래그로 회전, 휠로 확대, "시점 초기화"로 기본 시점 복귀
- 층을 클릭하거나 1F/2F 버튼으로 해당 층만 강조

## 아두이노 연결 (서보 4개)

B 건물(구조판)의 표지판 방향을 USB로 아두이노에 보내 실물 표지판 모형의 서보를 돌립니다.

1. 아두이노 IDE로 `arduino/gujopan_servo/gujopan_servo.ino`를 우노에 업로드합니다.
2. 서보 신호선을 3, 5, 6, 9번 핀에 연결합니다.
   - 서보 0: 1층 왼쪽 표지판, 서보 1: 1층 오른쪽 표지판
   - 서보 2: 2층 왼쪽 표지판, 서보 3: 2층 오른쪽 표지판
3. 서보 전원은 외부 5V에 연결하고, 외부 전원 GND와 아두이노 GND를 이어 줍니다. 서보 4개를 USB 전원으로 돌리면 보드가 재부팅될 수 있습니다.
4. `발표용 실행 (Mac).command`(윈도우는 `발표용 실행 (Windows).bat`)를 더블클릭합니다. 시뮬레이션이 `http://localhost:8765`로 크롬(없으면 엣지)에서 열립니다. 윈도우는 파이썬이 설치되어 있어야 합니다.
5. **처음 한 번만** 하단의 "아두이노 연결" 버튼을 눌러 포트를 고릅니다. 브라우저 보안 때문에 이 한 번은 건너뛸 수 없습니다.
6. 그다음부터는 같은 컴퓨터, 같은 브라우저에서 실행 파일로 열면 페이지가 켜지자마자 자동으로 연결됩니다. USB를 뽑았다 다시 꽂아도 자동으로 다시 연결됩니다.

발표 전 리허설 때 5번을 미리 해 두면, 발표 때는 실행 파일만 더블클릭하면 됩니다. `evac-compare.html`을 직접 더블클릭해서 열면 시뮬레이션은 보이지만, 허용 기록이 남지 않아 매번 버튼을 눌러야 할 수 있습니다.

화살표 각도(왼쪽 20°, 오른쪽 160°)와 회전 속도는 스케치 위쪽의 `ANGLE_LEFT`, `ANGLE_RIGHT`, `STEP_MS`에서 바꿀 수 있습니다.

시리얼 명령 형식은 115200bps, 한 줄에 하나 `S,<서보번호>,<L|R>`입니다. 예: `S,2,R`은 2층 왼쪽 표지판을 오른쪽으로 돌립니다.

## 참고

연기 확산, 이동 속도, 노출량 계산은 시연용으로 단순화한 모델이며 실측 데이터가 아닙니다.
