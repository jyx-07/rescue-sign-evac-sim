# ai — 대피 방향 판단 AI

시뮬레이션의 B 동(구조판) 화살표 방향은 AI가 정합니다. 두 가지 방식이 있고, 페이지가 자동으로 고릅니다.

1. **AI 서버 (이 폴더):** `http://localhost:8000`에 서버가 떠 있으면 페이지가 0.5초마다 판단을 물어봅니다.
2. **내장 신경망:** 서버가 없거나 응답이 없으면 페이지 안의 작은 신경망(입력 6, 은닉 12, 출력 1)을 씁니다. 페이지를 열 때 시뮬레이터로 만든 상황 4,000개로 학습하고, 검증 정확도를 화면에 표시합니다.

어느 쪽을 쓰는지는 화면 오른쪽 B 동 패널의 "AI · ..." 줄에 나옵니다.

## 서버 실행 (예시)

```
python ai/server_example.py
```

`server_example.py`는 파이썬 표준 라이브러리만 씁니다. 우리 AI 모델로 바꾸려면 `predict_right()` 함수 안만 고치면 됩니다.

## 입출력 형식

`GET /health`

```json
{ "ok": true, "name": "모델 이름" }
```

`POST /predict` (2개 층 × 8개 복도 구간 = 16개를 한 번에 보냄)

```json
{ "items": [ { "floor": 0, "segment": 0, "features": [0.06, 0.94, 0.0, 0.3, 0.0, 0.1] }, ... ] }
```

`features` 6개:

| 번호 | 뜻 | 범위 |
|---|---|---|
| 0 | 왼쪽 계단까지 거리 | 0~1 |
| 1 | 오른쪽 계단까지 거리 | 0~1 |
| 2 | 왼쪽 복도 경로의 연기량 | 0~4 |
| 3 | 오른쪽 복도 경로의 연기량 | 0~4 |
| 4 | 왼쪽 계단의 연기량 | 0~4 |
| 5 | 오른쪽 계단의 연기량 | 0~4 |

응답: 보낸 순서대로 "오른쪽 계단이 더 안전할 확률"

```json
{ "p_right": [0.02, 0.97, ...] }
```

페이지는 확률이 반대쪽으로 65% 이상 기울어야 화살표를 돌립니다.

## 주의

- 서버는 `Access-Control-Allow-Origin: *` 헤더를 보내야 합니다. 예시 서버에는 들어 있습니다.
- 페이지를 `발표용 실행` 파일로 열어야 서버에 접속합니다. html 파일을 직접 더블클릭해 열면 내장 신경망만 씁니다.
- 내장 신경망은 시뮬레이터가 만든 데이터로 학습했습니다. 실제 화재 데이터로 학습한 모델이 아닙니다.
